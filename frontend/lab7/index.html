Процесор (CPU)

Центральний процесор — мозок ПК. Обробляє всі команди та керує залізом.

2

Відеокарта (GPU)

GPU обробляє графіку. Це важливо для ігор та монтажу відео.

3

Системні вузли

Материнська плата: Об'єднує всі компоненти.

RAM: Тимчасова пам'ять для роботи програм.

SSD: Швидке зберігання ваших файлів.

Блок живлення: Дає енергію всій системі.
